# LokuOnX

Windows 11 用の録音アプリです（個人用・オンライン利用なし）。PC内部の音（スピーカー出力）とマイクを、1つまたは複数同時に録音できます。

## 使い方
1. [Releases](../../releases) から `LokuOnX-win-x64.zip` をダウンロードして展開します（インストール不要）。
2. `LokuOnX.exe` を起動します。`settings.ini` と `Profiles/` は、exe と同じフォルダに作られます。
3. 入力デバイス（🎤＝マイク、🔊＝PC音）を選び、「● 録音開始」を押します。「■ 停止」で保存されます。

保存先の既定は `ドキュメント\LokuOnX\Rec` の中の日付フォルダです。展開したフォルダごと移動すれば、設定ごと持ち運べます。

## 主な機能
- 形式: flac（既定）・mp3・aac(.m4a / .aac)・wav・ogg・opus。ビットレート・圧縮レベル・サンプリング周波数・チャンネルを指定可能
- 複数デバイスの同時録音（ミックスして1ファイル、またはデバイスごとに別ファイル）。デバイスごとのゲイン・メーター・波形
- 分割（手動ボタン・時間ごと・無音検出・24時間で強制）。途切れなく次のファイルへ
- 一時停止／再開、録音中のスリープ防止、ディスク残量の監視、異常終了後の復旧
- ファイル名テンプレート（`{Date}` `{Time}` `{No}` `{Track}` `{Start}` `{End}` `{Length}` `{Device}` `{Preset}`）、日付フォルダ、タグ（メタデータ）
- プロファイル（`Profiles/名前.json`）、録音履歴・フォルダ表示、プレイヤー（0.5〜2倍速・音程維持）、名前の変更、ごみ箱へ削除
- タスクトレイ常駐、ホットキー（Ctrl+Alt+F9/F10/F11）、予約録音、音が出たら自動で録音開始
- ASIO（上級者向け。設定の「詳細設定」でONにすると入力デバイスに出ます）
- 画面の色: 自動／ライト／ダーク／ソフト（試作）

## 困ったとき
- 長さが 00:00:58 のようにずれて見える `.aac` は、形式上の仕様です（音声は正しい）。長さを正しく見たいときは `.m4a` を使ってください
- 録音が異常終了した場合、次の起動時に残ったファイル（`_rec_*`）を整えるか確認が出ます
- 同じフォルダの exe を2つ起動すると警告が出ます（2つ目は設定を保存しません）。別のフォルダに置いたコピーは別々に動きます

## ビルド（開発者向け）
C# / .NET 8 / WPF。GitHub Actions（`.github/workflows/build.yml`）が単一ファイル発行し、FFmpeg（LGPL版）を取得・検査して同梱します。仕様の詳細は [PROJECT.md](PROJECT.md) にあります。
